# Final check-list (СТ КазНИТУ 09-2023)

Tick `[x]` while checking. Clause numbers in brackets.

## Page setup
- [ ] A4, printed on one side (5.1.2)
- [ ] Margins: top 20, bottom 25, left 30, right 10 mm (master's — 15 mm) (5.1.3)
- [ ] Times New Roman; body 14 pt; title/annotation 12 pt (5.1.4)
- [ ] Single («через один») line spacing; uniform text density (5.1.4)
- [ ] Paragraph indent uniform, five characters (~1.25 cm) (5.1.4)
- [ ] The whole text made in Microsoft Word (5.1.4)

## Numbering and volume
- [ ] Continuous page numbering, including the title page and appendices (5.1.8)
- [ ] Numbers centred at the bottom, no dot; first printed on the «ВВЕДЕНИЕ» page (5.1.8)
- [ ] Volume: diploma ≥ 30 pages, master's ≥ 60 (title pages/appendices excluded) (4.1.2)

## Composition
- [ ] All mandatory elements of this work type present (4.1, Table 1)
- [ ] Order of elements matches 4.1.1

## Structural headings
- [ ] «АННОТАЦИЯ», «СОДЕРЖАНИЕ», «ВВЕДЕНИЕ», «ЗАКЛЮЧЕНИЕ»/«ВЫВОДЫ», «СПИСОК
      ИСПОЛЬЗОВАННОЙ ЛИТЕРАТУРЫ», «ПРИЛОЖЕНИЕ» — uppercase, centred, not numbered (4.4–4.12)
- [ ] Annotation in three languages, on one page (4.4)
- [ ] Contents without dot leaders up to the page number (4.6)

## Text division and headings
- [ ] Sections/subsections/items numbered with Arabic digits, paragraph indent (5.2.2)
- [ ] No dot after a section/subsection number (5.2.2)
- [ ] Every section starts on a new page (5.2.2)
- [ ] Headings with the paragraph indent, capitalised, no dot, not underlined (5.2.3)
- [ ] One line between section and subsection headings; two lines between subsections (5.2.3)
- [ ] Lists: dash; references use a lowercase letter + bracket; deeper level Arabic digit +
      bracket (5.2.3)

## Wording
- [ ] Units per ГОСТ 8.417, constant for one parameter (5.3.3)
- [ ] No minus sign «−» in the text (write «минус») (5.3.5)
- [ ] No ⌀ sign in the text (write «диаметр») (5.3.5)
- [ ] No mathematical signs without numbers (>, <, =, №, %) — write words (5.3.5)
- [ ] Standard index never split from its designation (5.3.5)

## Tables (5.5)
- [ ] Caption above the table, paragraph indent, «Таблица N − Название», no dot after the number
- [ ] Table from the left edge, page-wide, a blank line after the caption
- [ ] Continuous numbering; in appendices — «Таблица А.1»
- [ ] Every table referenced in the text
- [ ] No «Номер по порядку» column
- [ ] When continued: «Продолжение таблицы N», header/sidebar repeated
- [ ] Table separated from the text by one blank line

## Figures (5.6)
- [ ] Caption below the figure, centred: «Рисунок N − Название»
- [ ] Every figure referenced in the text
- [ ] Continuous numbering; in appendices — «Рисунок А.3»

## Formulas (5.4)
- [ ] Continuous numbering; number right, in parentheses, at the formula's level
- [ ] At least one blank line above and below
- [ ] Symbol explanations start with «где» with the paragraph indent
- [ ] Typed with an equation editor (not scans)

## References, notes, footnotes (5.7–5.9)
- [ ] In-text references in square brackets `[1]`
- [ ] «Примечание –» (single, not numbered); several — «Примечания: 1 …; 2 …»
- [ ] Footnotes at the page bottom behind a short rule; numbering separate per page

## Bibliography (4.11, 5.7)
- [ ] Sources in order of appearance in the text
- [ ] Description per ГОСТ 7.1-2003; paragraph indent, no dot after the number

## Appendices (4.12)
- [ ] Each from a new page; letters А, Б, В … (without Ё, З, Й, О, Ч, Ы, Ъ, Ь)
- [ ] Numbering inside the appendix: «Таблица А.1», «Рисунок А.1», «(В.1)»
- [ ] «Продолжение А» on following sheets; continuous page numbering

## Graphics (section 6)
- [ ] Formats per ГОСТ 2.301-68; title block per ГОСТ 2.104-2006
- [ ] Scales per ГОСТ 2.302-68; lines per ГОСТ 2.303-68; fonts per ГОСТ 2.304-81
- [ ] Posters: 20 mm frame from the edge, heading at the top centre (6.8)

# Citations and bibliography (п. 4.11, 5.7, Приложение П)

## Citation rules

- In-text references use the source's **number in square brackets**: `[1]`, `[2]` (п. 4.11, 5.7).
- Sources are listed **in order of appearance** in the text (п. 4.11).
- Bibliographic description per **ГОСТ 7.1-2003** (п. 4.11).
- When citing a standard, give the **index together with the designation** (ГОСТ 7.32-2017,
  not «ГОСТ» in one place and «7.32-2017» in another), and never split them across lines or
  pages (п. 5.3.5).

## List formatting

- Heading **«СПИСОК ИСПОЛЬЗОВАННОЙ ЛИТЕРАТУРЫ»** — **UPPERCASE, centred, not numbered**.
- Sources are numbered with Arabic digits and printed **with the paragraph indent, no dot
  after the number**.
- Journal articles, conference proceedings, electronic sources, state and international
  standards are all allowed.

## Samples (Приложение П)

**Legislative act:**
```
1 Закон Республики Казахстан «О стандартизации» от 5 октября 2018 года № 183-VІ ЗРК.
```

**Act with amendments:**
```
2 Закон Республики Казахстан «О внесении изменений и дополнений в некоторые
  законодательные акты Республики Казахстан по вопросам науки» от 31 марта 2021 года
  № 24-VII ЗРК.
```

**Book / textbook (1–3 authors):**
```
3 Карибжанов Х., Амирханов Е., Хамитов И. Стандартизация: учебное пособие / под ред.
  Х.С. Карибжанова. – Нур-Султан: Национальный орган по стандартизации, 2020. – 224 с.
5 Лифиц И.М. Стандартизация, метрология и подтверждение соответствия: учебник и
  практикум для вузов / И. М. Лифиц. – 14-е изд., перераб. и доп. – Москва: Издательство
  Юрайт, 2022. – 423 с.
```

**Standard:**
```
4 ГОСТ 1.2-2015 «Межгосударственная система стандартизации. Стандарты
  межгосударственные, правила и рекомендации по межгосударственной стандартизации.
  Правила разработки, принятия, обновления и отмены» (изм. 1).
```

**Journal article:**
```
6 Баймаханов Г. А., Каражанова Д. Д., Шингисова Р. К. Методы управления рисками
  процессов качества // Научно-технический журнал «SMART». – Астана, РГП «КазСтандарт»,
  2022. – №4(83). – С. 56-51.
```

**English article:**
```
7 Greulich O.R., Jawad M.H. (eds.) Primer on Engineering Standards. / O.R. Greulich,
  M.H. Jawad. – New York: Wiley-ASME, 2018. – 163 p.
```

**Article in a collection:**
```
8 Поветкин В. В., Керимжанова М. Ф., Ибрагимова З. А., Татыбаев М. К., Исаева И. Н.
  Обоснование технологических способов повышения долговечности зубчатых колес //
  Международный сборник научных трудов «Прогрессивные технологии и системы
  машиностроения». – Донецк, 2015. – С. 165-171.
```

**Electronic resource:**
```
9 Ковачич Л. Китайский опыт развития искусственного интеллекта: стратегический подход.
  07.07.2020, https://carnegiemoscow.org/2020/07/07/ru-pub-82172.
```

**RF patent / RK innovation patent:**
```
10 Патент № 2305798 C1 RU F04D 1/04 Шнекоцентробежный насос / Мельников Н. А.,
   Потуроев А. А., Филатов В. А., 10.09.2007.
11 Инновационный патент РК № 30468 F15B 15/22 Грунтовый насос / Поветкин В.В.,
   Ермекбаева А.О., Керимжанова М.Ф., Андрющенко Е.С. Опубл. 15.10.2015, бюл. № 10.
```

**Four or more authors:** either the first four plus «и др.», or all authors (ГОСТ 7.1-2003
allows both; КазНИТУ lists usually enumerate all).

## Sources allowed for citation (п. 5.7)

Standards applied in the Republic of Kazakhstan, legislative and normative acts, special
literature, etc.
